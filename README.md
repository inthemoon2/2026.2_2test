# 사회문제 해결 기계학습 프로젝트 — 조별 수행평가 사이트

7개 반, 반마다 진로 분야별 조(3~5명)가 **하나의 프로젝트 공간을 함께 쓰며** 문제 정의 → 데이터 → 모델 → 결과 분석 → AI 윤리 → 발표 자료를 작성하고, 마지막에 **교사에게 제출**하는 사이트입니다.
선생님은 관리자 페이지에서 **명단 업로드 · 비밀번호 발급 · 진행 현황 · 가상 채점 · 개인 조정 · 동료평가 가져오기 · 세특 재료**를 한곳에서 처리합니다.

```
학생·교사 브라우저 ──▶ GitHub Pages (화면: index / admin / report)
                          │  fetch (text/plain)
                          ▼
                    Google Apps Script (Code.gs, 서버)
                          ├─ 구글 시트  : 모든 기록 (조, 학생, 내용, 점수, 이력, 제출)
                          └─ 구글 드라이브 : CSV · 이미지 · 발표 자료
```

돈이 들지 않고(구글·깃허브 무료), 서버를 따로 빌릴 필요가 없어요. 대신 **구글 계정 1개(선생님)** 가 서버 역할을 합니다.

## 폴더 구성

| 파일 | 역할 |
|---|---|
| `index.html`, `assets/app.js` | 학생 화면 (로그인, 팀 홈, 단계별 작성, 제출) |
| `admin.html`, `assets/admin.js` | 관리자 화면 |
| `report.html`, `assets/report.js` | 제출 후 만들어지는 보고서 페이지 + PDF 저장 |
| `assets/common.js`, `assets/style.css` | 공통 코드, 디자인 |
| `config.js` | **서버 주소(API_URL)를 넣는 곳 — 선생님이 고칠 파일은 이것 하나** |
| `apps-script/Code.gs` | 서버 코드 전체 (구글 Apps Script에 붙여넣기) |
| `apps-script/appsscript.json` | Apps Script 설정(선택) |
| `.github/workflows/pages.yml` | 깃허브에 올리면 자동으로 사이트를 공개해 주는 설정 |
| `samples/` | 연습용 가짜 명단 3종 (역할표, 학번 명부, 동료평가) — **실제 학생 이름이 아닙니다** |

## 설치 — 처음 한 번만 (약 20~30분)

### 1단계. 구글 시트 만들기
1. 구글 드라이브 → **새로 만들기 → Google 스프레드시트**
2. 이름을 `사회문제해결프로젝트_DB` 처럼 알아보기 쉽게 바꿉니다. (이 시트가 모든 기록의 저장소예요. 탭은 사이트가 알아서 만듭니다.)

### 2단계. 서버 코드 붙여넣기
1. 시트 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다. (새 탭에 코드 편집기가 열려요)
2. 가운데 편집창에 이미 있는 `function myFunction() {}` 를 **모두 지우고**, 이 폴더의 `apps-script/Code.gs` 내용을 **전부 복사해서 붙여넣기** 합니다.
3. 위쪽 💾 **저장** (Ctrl+S).

### 3단계. 관리자 비밀번호 정하기
1. 편집기 왼쪽의 **⚙ 프로젝트 설정** 클릭
2. 맨 아래 **스크립트 속성 → 스크립트 속성 추가**
3. 속성 `ADMIN_PASSWORD`, 값 `선생님만 아는 비밀번호` → **스크립트 속성 저장**
   - 이 비밀번호는 코드나 깃허브에 올라가지 않아요. 길고 추측하기 어렵게 정하세요.

### 4단계. 웹 앱으로 배포하고 주소 복사하기
1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴(유형 선택) → **웹 앱**
3. 설정
   - 설명: `v1`
   - **다음 사용자 인증으로 실행: 나** (선생님 계정)
   - **액세스 권한이 있는 사용자: 모든 사용자**
4. **배포** → 처음엔 **액세스 승인** 창이 떠요. 계정 선택 → "고급" → "(안전하지 않음)으로 이동" → **허용**
   (본인이 만든 스크립트라서 나오는 경고예요. 시트·드라이브 접근 권한 요청입니다.)
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 **복사**합니다.
6. 이 폴더의 `config.js` 를 열어 `API_URL` 의 따옴표 안에 붙여넣고 저장합니다.

> 브라우저 주소창에 그 URL을 열었을 때 `{"ok":true,"message":"API가 정상 동작 중입니다.", ...}` 가 보이면 서버 준비 완료입니다.

### 5단계. 깃허브에 올려서 사이트 공개하기
1. [github.com](https://github.com) 로그인 → 오른쪽 위 **＋ → New repository**
   - 이름: `ml-social-project` (원하는 이름) / **Public** / 나머지는 그대로 → **Create repository**
2. **방법 A (가장 쉬움, 컴퓨터에 아무것도 설치 안 해도 됨)**
   - 저장소 화면의 **uploading an existing file** 링크 클릭
   - 이 폴더 안의 파일·폴더를 **전부 드래그** (`index.html`, `admin.html`, `report.html`, `config.js`, `assets/`, `apps-script/`, `samples/`, `.github/`, `README.md`)
     - ⚠ 점(.)으로 시작하는 `.github` 폴더가 윈도우/맥에서 안 보일 수 있어요. 보이지 않으면 방법 B를 쓰거나, 저장소에서 **Add file → Create new file** 로 `.github/workflows/pages.yml` 파일을 직접 만들어 내용을 붙여넣으세요.
   - 맨 아래 **Commit changes**
3. **방법 B (깃을 쓸 줄 안다면)**
   ```bash
   cd ml-social-project
   git init && git add . && git commit -m "첫 배포"
   git branch -M main
   git remote add origin https://github.com/내아이디/ml-social-project.git
   git push -u origin main
   ```
4. 저장소 **Settings → Pages → Build and deployment → Source: `GitHub Actions`** 로 선택합니다.
5. 저장소 **Actions** 탭에서 `Deploy to GitHub Pages` 가 초록 ✔ 가 될 때까지 기다립니다(1~2분).
   - 초록이 안 되면 **Run workflow** 를 눌러 다시 실행하세요.
6. 주소: `https://내아이디.github.io/ml-social-project/` → 학생 화면, `…/admin.html` → 관리자 화면

> 이후 `config.js` 나 화면 파일을 고쳐서 다시 올리면(Commit) 자동으로 다시 배포돼요.
> **서버 코드(Code.gs)를 고친 경우**는 깃허브가 아니라 Apps Script 에서 **배포 → 배포 관리 → ✏ 수정 → 버전: 새 버전 → 배포** 를 해야 반영됩니다. (가장 흔한 실수예요!)

## 학기 운영 순서 (관리자)

관리자 페이지(`…/admin.html`) → 비밀번호 입력

1. **명단 · 비밀번호 탭 → ① 역할표 올리기**
   - 반 번호 입력 → 역할표 파일 선택 (엑셀 `.xlsx` · CSV · 또는 표를 복사해 붙여넣기)
   - 파일 모양: 첫 열 `조`, `분야`, 그 다음 `①프로젝트 매니저 … ⑤AI 윤리·소통 담당` 5칸에 **이름을 쉼표로** (제목 줄이 2줄이어도 괜찮아요). 연습용은 `samples/샘플_1반_역할표.csv`.
   - 미리보기에서 인원·역할 비어 있음 같은 **경고**를 확인하고 "조 만들기 / 갱신"
   - 한 학생이 여러 역할이면 여러 칸에 같은 이름을 적으면 하나로 합쳐집니다.
2. **② 학번 명부 올리기** — `학번`, `이름` 열이 있는 파일 (연습용 `samples/샘플_1반_학번명부.csv`). 이름으로 연결해요. 동명이인이나 누락은 "채점 · 세특 재료" 탭에서 직접 입력할 수 있습니다.
3. **③ 비밀번호 발급** — 조별 6자리가 만들어져요. **그 자리에서 CSV 저장 또는 인쇄**(쪽지)하세요. 시트에는 암호화된 값만 남아서 나중에 다시 볼 수 없습니다(재발급은 가능).
4. 학생들에게 **사이트 주소 + 학번 + 이름 + 조 비밀번호**를 안내합니다.
5. **진행 현황 탭** — 조별 전체/단계별 작성 비율, 마지막 수정, 비밀번호 미발급·학번 누락 경고.
6. 제출 후 **채점 · 세특 재료 탭**
   - 조 선택 → 4개 평가 요소마다 **가상 채점(제안 점수 + 충족/미충족 근거)** 을 보고, 평가 기준 문구가 그대로 적힌 4단계 중 선택해 **조 점수 저장**
   - 학생별 **개인 조정**(사유 필수) · **결석**(기본 점수 30점, 설정에서 변경) · **동료평가 환산 점수(0~20)** 입력
   - **세특 재료**: 조 요약, 본인이 쓴 기여 글, 기재 금지 가능 단어 표시
7. **동료평가 가져오기 탭** — 파일을 올리고 평가자 · 평가받은 학생 · 점수 열을 고르면 학생별 평균(원점수)이 저장됩니다. 20점 환산은 기준이 정해진 뒤 직접 입력해요.
8. **채점표 탭** — 학생별 점수 총괄표(CSV 내려받기). 같은 내용이 시트의 `채점표` 탭에도 자동으로 갱신됩니다.
9. 제출 후 수정이 필요한 조는 **진행 현황 → 수정 허용** (보고서 링크는 그대로 유지, 다시 제출하면 갱신).

## 학생이 보는 흐름

로그인(학번·이름·조 비밀번호) → **팀 홈**(역할·진행률·평가 기준) → 1. 문제 정의·수행 계획 → 2. 데이터 수집·전처리(CSV 업로드) → 3. 모델 개발·평가 → 4. 결과 분석·해결 방안 → 5. AI 윤리 점검 → 6. 발표 자료 · 나의 기여 · **교사에게 제출하기**

* 글을 쓰면 1.5초 뒤 **자동 저장**, 조원 변경은 8초마다 반영, "접속 중인 조원"이 표시됩니다.
* 같은 칸을 동시에 고치면 덮어쓰지 않고 **충돌 안내**(조원 내용으로 바꾸기 / 둘 다 남기기 / 내 내용으로 덮어쓰기)가 나옵니다.
* "나의 기여" 칸은 **본인만** 쓸 수 있어요.
* 제출하면 **수정 잠금** → 보고서 링크 + **PDF로 저장하기** 버튼. (PDF는 인쇄 창에서 "대상: PDF로 저장")

## 가상 채점은 무엇을 보나요?

글의 **형식과 완성도**만 규칙으로 점검해 점수를 "제안"합니다. 규칙은 `Code.gs` 의 `VS_TABLE`(점수 구간)과 항목별 `min`(권장 글자 수)에서 바꿀 수 있어요.

| 요소 | 점검 예 | 점수 규칙 |
|---|---|---|
| 기획안 | SDGs 선택, 문제·필요성 분량, 5단계 계획 작성, 역할·협업 | 모두 충족 20 / 핵심 충족+3단계 이상 14 / 그 외 8 |
| 전처리 | 출처·신뢰 근거, 데이터 업로드·구조 설명·개인정보 확인, 결측·이상치 처리 기록, 변수 설정, 분할 비율, 정규화 | 7개 중 7→20, 5~6→16, 3~4→12, 그 이하 8 |
| 모델 생성 | 문제 유형 판단, 모델 선택 이유, 코랩 링크/캡처, 학습 결과, 설정값 / **문제 유형과 모델이 안 맞으면 8점 + 경고** | 5개 중 5→20, 4→16, 3→12, 그 이하 8 |
| 모델 평가 | **테스트 데이터 사용**, 문제 유형에 맞는 지표, 시각화, 해석, 오차·한계, 개선 방향, 개선 시도, 윤리 반영 / **훈련 데이터로만 평가하면 8점 + 경고** | 8개 중 7+→20, 5~6→16, 3~4→12, 그 이하 8 |

⚠ **내용이 맞는지(해석의 타당성, 데이터의 적절성)는 판단하지 못해요.** 최종 점수는 항상 선생님이 정합니다.

평가 요소와 역할의 관계: 평가 요소는 4개(기획안·전처리·모델 생성·모델 평가)지만 역할은 5개라서 **일대일 대응이 아닙니다.** 그래서 조 점수는 "조 단위 결과물" 기준으로 주고, 역할 편차는 **개인 조정(사유 기록) + 동료평가 + 학생별 활동 기록(수정 이력)** 으로 반영하도록 설계했어요. AI 윤리·소통 담당의 기여는 모델 평가의 "사회적 영향 반영"과 동료평가에서 드러납니다.

## 개인정보 · 보안 — 꼭 알아 두세요

* **로그인**: 학번 + 이름 + 조 비밀번호입니다. 구글 계정 로그인보다 약해서 비밀번호가 새면 같은 조가 아닌 사람이 들어올 수 있어요. 비밀번호 5회 오류 시 10분 잠금, 로그인 정보는 12시간(관리자 8시간) 후 만료됩니다. 비밀번호는 "발급 화면"에서만 보이고 시트에는 해시값만 저장돼요.
* **보고서 링크**: 링크(24자 무작위 주소)를 아는 사람은 **로그인 없이** 볼 수 있어요. 이름과 역할이 보이지만 **학번은 보이지 않습니다.** 링크를 외부 공개 게시판에 올리지 마세요.
* **업로드 파일**: 드라이브에 저장되고 "링크가 있는 사용자 보기"로 공유됩니다(코랩에서 바로 읽기 위해). 학교 계정 정책으로 막혀 있으면 코랩 불러오기가 안 될 수 있어요. 학생들에게 **개인정보(이름·연락처·얼굴 등)가 든 데이터는 올리지 않도록** 안내하세요(작성 화면에 확인 체크가 있어요).
* **시트 공유**: 구글 시트에는 학생 이름·학번·점수가 있습니다. 시트를 다른 사람과 공유하지 마세요. 이 저장소(깃허브)에는 학생 정보가 올라가지 않아요 — `config.js` 의 서버 주소만 들어갑니다. (서버 주소가 공개돼도 관리자·학생 기능은 비밀번호 없이 쓸 수 없지만, 불안하면 저장소를 Private 으로 두고 Pages 를 쓰는 유료 플랜을 고려하세요.)
* **학교 계정 사용 시**: 학교 Google Workspace 는 관리자가 "모든 사용자 웹 앱 배포"나 "링크 공유"를 막았을 수 있어요. 안 되면 개인 구글 계정으로 만들거나 학교 정보부(관리자)에 문의하세요.

## 한계와 주의 (정직하게)

* 구글 서버(Apps Script) 응답은 1~3초 걸릴 수 있고, **동시에 쓰는 사람이 아주 많으면(수십 명이 같은 순간 저장) 잠시 "지연" 안내가 나올 수 있어요.** 수업 시간에 7개 반이 전부 동시에 쓰는 규모는 시험하지 못했습니다. 첫 수업은 한 반으로 시작해 보세요.
* CSV는 **5MB까지** 올릴 수 있고, 더 크면 "데이터 원본 링크" 칸을 쓰게 했어요.
* 하루 실행량 등 구글 무료 할당량이 있습니다. 학교 규모에서는 보통 충분하지만, 평가 마감 직전에 몰리는 날은 여유를 두세요.
* 가상 채점 · 세특 재료의 "주의 단어" 검사는 **간단한 규칙**이라 놓치는 경우가 있어요. 세특은 반드시 **해당 학년도 학교생활기록부 기재요령**(글자 수, 문장 끝 형식, 기재 금지 항목)을 직접 확인하고, 교사가 관찰한 내용으로 작성하세요.
* 동료평가 파일 형식을 몰라서 **열 연결 방식**으로 만들었습니다. "한 줄 = 한 사람이 한 사람을 평가" 형태를 가정해요. 표가 "평가자 한 줄에 조원별 점수가 가로로" 있는 형태라면 알려 주세요 — 맞춰서 바꿔 드릴 수 있어요.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 로그인 화면에 "서버 주소가 설정되지 않았어요" | `config.js` 의 `API_URL` 을 붙여넣고 다시 올렸는지 |
| "서버 응답을 읽을 수 없어요" | 배포 설정이 **액세스: 모든 사용자**인지, URL 이 `/exec` 로 끝나는지 |
| 코드를 고쳤는데 반영이 안 돼요 | Apps Script **배포 관리 → 수정 → 새 버전 → 배포** |
| 관리자 로그인: "ADMIN_PASSWORD 가 설정되지 않았다" | 3단계 스크립트 속성 이름/값 철자 |
| 파일 업로드가 안 돼요 | 5MB(CSV·이미지)/10MB(PDF·PPT) 이하인지, 확장자가 맞는지 |
| 한글이 깨진 CSV | 엑셀 "CSV UTF-8"로 저장하거나, 그대로 올려도 자동 인식(CP949)합니다. 코랩에서는 `encoding='cp949'` 코드를 안내해요 |
| "접속자가 많아 지연" | 몇 초 뒤 자동 재시도됩니다. 계속되면 동시에 저장하는 인원을 줄여 보세요 |
| 깃허브 Actions 가 빨간 ✗ | Settings → Pages → Source 가 "GitHub Actions" 인지, 저장소가 Public 인지 |
| 학번 연결이 안 되는 학생 | 이름이 역할표와 명부에서 똑같은지(띄어쓰기), 동명이인은 채점 탭에서 학번 직접 입력 |
